API 调用命令

Python SDK 调用
from modelscope import pipeline

pipe = pipeline('text-generation', model='Qwen/Qwen2.5-7B-Instruct')
result = pipe('你好，请介绍一下自己')
print(result)
curl 调用
curl -X POST "https://api-inference.modelscope.cn/api/v1/models/Qwen/Qwen2.5-7B-Instruct" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": {"messages": [{"role": "user", "content": "你好"}]}}'
免费额度：ModelScope API-Inference 每日提供 2000 次免费调用，覆盖 5000+ 开源模型。高并发场景建议使用 DashScope 商业 API。

🔄 数据迁移

从旧版本 Q-Paw 目录合并数据到当前目录。

迁移命令

Windows
migrate.bat
macOS / Linux
./migrate.sh

迁移策略

  • 模型 — 复制到新目录，已存在则跳过
  • 数据（聊天记录、技能等）— 复制较新文件，不覆盖已有
  • 配置 — 智能合并：保留新配置结构 + 补充旧配置中的自定义值

📖 使用指南

快速开始

1. 初始化环境

:: Windows
setup.bat

# macOS / Linux
chmod +x setup.sh && ./setup.sh

脚本会自动下载 Python、安装 QwenPaw 及依赖，全部使用国内镜像加速。

2. 配置 API Key

在「API 配置」页面填写至少一个提供商的 API Key，然后导出配置。

3. 启动 QwenPaw

:: Windows
launch.bat

# macOS / Linux
./launch.sh

镜像加速 & 包管理说明

uv 是 Astral 团队开发的 Python 包管理器，安装速度比 pip 快 10-100 倍。

Q-Paw 默认使用 uv，如果 uv 安装失败则自动回退到 pip，两种方式都能正常工作。

组件包管理国内镜像回退
uv 二进制—NPMMirrorGitHub
Python 嵌入包—NPMMirror / 华为云python.org
Miniconda—清华 TUNAanaconda.com
QwenPaw 等包uv 优先 / pip 兜底阿里云 / 清华 / 华为云pypi.org
ModelScope 模型—魔搭（国内直连）—

目录结构

Q-Paw/
├── index.html          ← 本控制台
├── setup.bat / .sh     ← 环境初始化（自动安装 uv + Python）
├── launch.bat / .sh    ← 启动 QwenPaw
├── model-manager.bat / .sh  ← 模型管理
├── migrate.bat / .sh   ← 数据迁移
├── cleanup.bat         ← 清理空间
├── bin/                ← uv 等工具二进制
├── python/             ← 便携 Python
├── models/             ← 本地模型
├── data/               ← 聊天记录、技能
├── config/             ← 配置文件
└── logs/               ← 日志
